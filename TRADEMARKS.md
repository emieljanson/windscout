# WindScout name and branding

The software license does not grant rights to use the Windscout name, logo, or
distinctive product branding in a way that suggests sponsorship, endorsement,
or official status.

You may accurately say that a project is based on Windscout, derived from
Windscout, or compatible with Windscout. If you distribute a modified version,
use a different product name and visual identity unless you have explicit
permission to present it as an official Windscout release.

Unmodified copies may retain the existing project name and attribution. These
guidelines do not limit fair or legally permitted descriptive use of the name.
